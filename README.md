# Kétrin Sérgio — Landing Page

Landing page single-page em HTML, CSS e JavaScript puro, construída a partir da identidade visual fornecida.

## Identidade
- Terracota: #A85D48
- Off-white: #F7F3EE
- Grafite: #242321
- Areia: #D8C5B5
- Taupe: #8B817A
- Tipografia principal: Playfair Display
- Tipografia de apoio: Montserrat

## Estrutura
- `index.html` — conteúdo e estrutura semântica
- `style.css` — identidade visual, responsividade e animações
- `script.js` — menu mobile, reveal on scroll e feedback dos conteúdos

## Antes de publicar
1. Inserir fotografia profissional real.
2. Confirmar número da OAB, cidade/endereço e canais de contato.
3. Substituir os conteúdos demonstrativos pelos conteúdos aprovados pela profissional.
4. Revisar a publicidade à luz das regras da OAB aplicáveis.
5. Configurar domínio, favicon, Open Graph e analytics somente se desejados.

O conteúdo evita promessas de resultado e exposição de casos concretos; isso deve ser mantido na versão final.
